# AI-Driven Security Operations Center (SOC)

An AI/ML-based Security Operations Center project focused on intelligent threat detection using machine learning techniques.

## Project Overview

This project explores the use of machine learning to identify potential security threats from cybersecurity data. It includes data preprocessing, model training, model comparison, and performance evaluation.

## Machine Learning Models

* Logistic Regression
* Random Forest

## Technologies Used

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Machine Learning

## Project Workflow

1. Dataset inspection
2. Data preprocessing
3. Machine learning model training
4. Model comparison
5. Performance evaluation
6. Confusion matrix visualization

## Project Files

| File                   | Description                       |
| ---------------------- | --------------------------------- |
| `check_dataset.py`     | Checks and explores the dataset   |
| `preprocess.py`        | Performs data preprocessing       |
| `train_model.py`       | Trains the machine learning model |
| `compare_models.py`    | Compares model performance        |
| `confusion_matrix.py`  | Generates the confusion matrix    |
| `confusion_matrix.png` | Model evaluation visualization    |

## Evaluation Metrics

The models are evaluated using:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix

## Dataset

The project uses a publicly available cybersecurity/IDS dataset. The dataset files are not included in this repository due to size and repository management considerations.

## Purpose

The main objective of this project is to explore how machine learning can support Security Operations Centers by assisting with automated threat detection and analysis.
